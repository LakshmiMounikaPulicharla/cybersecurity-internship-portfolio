# Task 6 – Introduction to Cryptography

### Description
This repository contains Task 6 of the Cyber Security Internship. This task focuses on understanding cryptography concepts and performing practical experiments using AES encryption, RSA key generation, hashing, and studying real-world security applications.

### Topics Covered
- Introduction to Cryptography  
- Symmetric Encryption (AES)  
- Asymmetric Encryption (RSA)  
- RSA Key Generation  
- File Encryption using OpenSSL  
- Hashing and Data Integrity  
- Real-world use of Cryptography (HTTPS and VPN)

### Tools Used
- OpenSSL  
- Ubuntu Linux 

### Files Included
- task6.pdf – Contains complete documentation of cryptography concepts, commands, screenshots, and explanations.
