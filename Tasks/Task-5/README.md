# Task 5 – Malware Types & Behavior Analysis

This repository contains Task 5 of the Cyber Security Internship.

In this task, I studied different types of malware such as viruses, worms, trojans, and ransomware.  
I used VirusTotal to analyze malware hashes and understand their detection and behavior.

This task helped me understand how malware spreads, how it is detected, and how systems can be protected.
