# Task - 15 : Vulnerability Assessment and Risk Prioritization

## Task Overview
This project demonstrates vulnerability assessment using Nessus Essentials on Ubuntu system. The task involves scanning the target system, identifying vulnerabilities, analyzing CVE and CVSS scores, and prioritizing risks.

## Tool Used
- Nessus Essentials
- Ubuntu OS

## Target
- Localhost (127.0.0.1)

## Methodology
1. Defined scope and target system
2. Configured Nessus vulnerability scanner
3. Performed vulnerability scan
4. Analyzed vulnerabilities using CVE and CVSS
5. Classified vulnerabilities based on risk
6. Prioritized vulnerabilities
7. Reviewed remediation recommendations

## Outcome
- Vulnerabilities identified and categorized
- Risk Priority List created
- Remediation steps documented

## Files Included
- Vulnerability Assessment Report
- Risk Priority List
- Scan Result Screenshots
