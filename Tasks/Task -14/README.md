# Task - 14 : TLinux Server Hardening & Secure Configuration

## Overview
This task demonstrates Linux server hardening using Ubuntu. The objective is to secure the system by reducing vulnerabilities and applying security configurations.

## Tools Used
- Ubuntu Linux
- SSH
- UFW Firewall
- Systemctl
- APT Package Manager
- Linux File Permission Utilities
- System Logs
- Lynis Security Auditing Tool

## Tasks Performed
- Reviewed system users, services, and open ports
- Restricted sudo access
- Hardened SSH configuration
- Updated system and enabled automatic updates
- Configured firewall rules
- Disabled unnecessary services
- Secured sensitive file permissions
- Monitored system logs
- Performed security audit using Lynis

## Outcome
Successfully implemented Linux hardening techniques to protect the system from common cyber threats.
